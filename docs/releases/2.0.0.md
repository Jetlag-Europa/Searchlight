Searchlight 2.0 makes games importable. A game is a single file with its play area, hiding zones and questions, and game makers import it themselves. Nothing is looked up in OpenStreetMap while you play, so answers are the same for everyone.

Every change since [1.0](https://github.com/Jetlag-Europa/Searchlight/releases/tag/v1.0.0) is in the [list of commits](https://github.com/Jetlag-Europa/Searchlight/compare/v1.0.0...v2.0.0).

## For game makers

- Import games yourself on `/games/import`. It draws the file on the map, checks it for mistakes and can fix regions that overlap. `/designer` previews a file without logging in.
- Publish a fix to a game at any time. Sessions already playing it see "Game update available", and their creator can switch to the new version when it suits them.
- The [game creation guide](https://searchlight.jetlageuropa.org/skills/create-game.md) takes you from a Discord announcement and a Google My Map to a finished game.
- Keep a game off the list and hand out a link to it instead, also to players who aren't on its Discord server.

## For players

- **Curses** that make the hiding zones bigger or smaller.
- See how many hiding zones are left, and in planning mode how many each answer would leave.
- Measuring questions show your distance to the nearest place being measured.
- Name your questions, see which types were already asked, and undo a delete.
- With Follow Me on, new questions start where you are.
- Distances are in kilometres unless you chose otherwise.
- Lots of fixes, and much better performance: the map stays responsive while questions are worked out.

## Removed

- Free play: every session plays a game, and the built-in OpenStreetMap questions are gone. "Same train line" and a few others have no equivalent yet.
- The Google Analytics and Microsoft Clarity tracking that came with @taibeled's original JetLagHideAndSeek and reported to its author's accounts. Searchlight has no analytics.
- In-app feedback. "Report a bug / suggest a feature" opens [GitHub Issues](https://github.com/Jetlag-Europa/Searchlight/issues/new/choose).
